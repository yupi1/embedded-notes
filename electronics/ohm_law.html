Закон
Ома

Фундаментальне співвідношення між напругою, струмом та опором у електричному колі. Сформульований Георгом Омом у 1827 році — основа аналізу будь-якого електричного кола, від простого резистора до складної схеми.

01 — Визначення

Закон Ома стверджує: сила струму I, що протікає через провідник, прямо пропорційна напрузі U на його кінцях і обернено пропорційна опору R провідника. Опір — це міра того, наскільки матеріал «чинить опір» проходженню заряду.

KEY
Аналогія з водою: Напруга — це тиск води у трубі, струм — швидкість потоку води, опір — звуження труби. Більший тиск (U) штовхає більше води (I) через ту саму трубу. Вужча труба (більший R) пропускає менше води при тому самому тиску.
02 — Формули та трикутник Ома

Базова формула U = I × R має ще два похідні варіанти. Закривши пальцем потрібну величину у трикутнику — отримуєш формулу для її обчислення.

Трикутник Ома — U / I / R U = I·R
U = I × R напруга
I = U / R струм
R = U / I опір

04 — Потужність

Електрична потужність P = U × I показує, скільки енергії розсіюється (зазвичай у вигляді тепла) за секунду. Підставивши закон Ома, отримуємо ще дві корисні форми — зручні, коли відоме лише одне з U/I.

WRN
Резистор має номінальну потужність (зазвичай 1/8–1 Вт у дрібних SMD/THT резисторах). Якщо розрахована P перевищує номінал — резистор перегріється і вийде з ладу. Завжди перевіряй P = I²×R перед вибором резистора в схему.
ERR
Derating (зниження номіналу): Номінальна потужність резистора (наприклад 0.25 Вт) вказана при температурі довкілля ~25–70°C. При вищій температурі допустиму потужність зменшують за derating-кривою з даташита — зазвичай лінійно до нуля при максимальній робочій температурі (~125–155°C). Типове правило для практики: не навантажуй резистор більш ніж на 50% від номіналу — це дає запас на нагрів від сусідніх компонентів, погану вентиляцію та довготривалу надійність (менше дрейфу опору, довший термін служби).
05 — Послідовне та паралельне з'єднання

Закон Ома застосовується до кожної ділянки кола окремо, тому загальний опір залежить від того, як з'єднані резистори.

Послідовно
Rзаг = R1 + R2 + R3 опір сумується

Струм однаковий через всі елементи. Напруга ділиться пропорційно опору кожного резистора (дільник напруги).

Паралельно
1/Rзаг = 1/R1 + 1/R2 + 1/R3 обернені сумуються

Напруга однакова на кожній гілці. Струм ділиться обернено пропорційно опору — більше тече через менший R.

INF
Для двох резисторів паралельно є зручна спрощена формула: Rзаг = (R1 × R2) / (R1 + R2) — «добуток на суму».
2× R послідовно → Rзаг = 2R сума
2× R паралельно → Rзаг = R / 2 половина

Окремий випадок, який легко тримати в голові: два однакові резистори R, з'єднані послідовно, дають подвоєний опір (2R), а з'єднані паралельно — половину опору (R/2). Це випливає з загальних формул, але корисно знати напам'ять для швидкої прикидки в голові без калькулятора.

06 — Опір провідника та температура

Опір самого провідника залежить від матеріалу, довжини, перерізу та температури:

R = ρ × L / A провідник
  • ρ (питомий опір) — властивість матеріалу (мідь ≈ 1.68×10⁻⁸ Ω·м, алюміній вищий, срібло нижчий).
  • L (довжина) — опір прямо пропорційний довжині: довший провід → більший опір.
  • A (площа перерізу) — опір обернено пропорційний площі: товстіший провід → менший опір.
  • Температура — у більшості металів опір зростає з температурою (позитивний температурний коефіцієнт). У напівпровідників — навпаки.
ERR
Закон Ома виконується не завжди. Він справедливий лише для «омічних» елементів (резистори, провідники за сталої температури). Діоди, транзистори, лампи розжарювання — нелінійні: їхній опір змінюється залежно від прикладеної напруги/струму, графік U(I) не є прямою лінією.
07 — Код — вимірювання струму через резистор-шунт
C · STM32 HAL — вимірювання струму через шунт (закон Ома) 
/* Вимірюємо падіння напруги на шунтовому резисторі через АЦП
   і обчислюємо струм по закону Ома: I = U / R */

#include "main.h"

#define SHUNT_R      0.1f     // опір шунта, Ом
#define VREF         3.3f     // опорна напруга АЦП, В
#define ADC_RES      4095.0f  // 12-бітний АЦП

ADC_HandleTypeDef hadc1;
UART_HandleTypeDef huart2;

static float adc_to_voltage(uint32_t raw) {
    return ((float)raw / ADC_RES) * VREF;
}

void MeasureShuntCurrent(void) {
    uint32_t raw;

    HAL_ADC_Start(&hadc1);
    if (HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK) {
        raw = HAL_ADC_GetValue(&hadc1);
    } else {
        raw = 0;
    }
    HAL_ADC_Stop(&hadc1);

    float u_shunt = adc_to_voltage(raw);     // напруга на шунті, В

    /* Закон Ома: I = U / R */
    float current = u_shunt / SHUNT_R;          // струм, А

    /* Потужність, що розсіюється на шунті: P = U × I = I² × R */
    float power = u_shunt * current;

    char msg[96];
    int len = snprintf(msg, sizeof(msg),
        "U=%.4f V  I=%.4f A  P=%.4f W\r\n",
        u_shunt, current, power);

    HAL_UART_Transmit(&huart2, (uint8_t*)msg, len, HAL_MAX_DELAY);
}

int main(void) {
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_ADC1_Init();
    MX_USART2_UART_Init();

    while (1) {
        MeasureShuntCurrent();
        HAL_Delay(500);
    }
}
08 — Питання на співбесіді

Сила струму в провіднику прямо пропорційна напрузі на його кінцях і обернено пропорційна опору провідника: I = U / R, або у звичній формі U = I × R.

Закон справедливий для омічних (лінійних) елементів за сталої температури — резисторів, провідників. Для нелінійних елементів (діод, лампа розжарювання) це співвідношення не є прямою лінією.

У металах носії заряду — вільні електрони, що рухаються між атомами кристалічної решітки. При нагріванні атоми коливаються інтенсивніше, частіше «заважаючи» руху електронів — це збільшує опір.

Цей ефект описують через температурний коефіцієнт опору α: R(T) = R₀ × (1 + α × ΔT). У напівпровідників навпаки — з ростом температури звільняється більше носіїв заряду, тому опір падає.

Послідовно: резистори з'єднані «в ланцюжок», через них тече однаковий струм. Загальний опір — це сума опорів: R = R1+R2+...; загальний опір завжди більший за найбільший окремий резистор.

Паралельно: резистори з'єднані «гілками» між тими ж двома вузлами, напруга на них однакова. Обернені опори сумуються: 1/R = 1/R1+1/R2+...; загальний опір завжди менший за найменший окремий резистор.

Базова формула P = U × I. Підставивши U = I × R, отримуємо P = I² × R.

Якщо ж відома лише напруга й опір, підставляють I = U/R та отримують P = U² / R. Всі три формули еквівалентні і дають однаковий результат — обирай ту, для якої відомі величини у задачі.

Коротке замикання — це з'єднання двох точок кола провідником з опором, що прямує до нуля (R → 0). За законом Ома I = U / R: коли R стає дуже малим при тій самій напрузі джерела, струм I стає дуже великим — обмежується вже лише внутрішнім опором джерела живлення та провідників.

Великий струм виділяє велику потужність (P = I²R) у дротах і компонентах — звідси перегрів, пожежі, вихід з ладу. Тому в реальних схемах обов'язково ставлять запобіжники або обмежувачі струму.
