01

Поняття

Schmitt Trigger (тригер Шмітта) — це компаратор або цифровий вхід із гістерезисом. Використовується для перетворення повільних або шумних аналогових сигналів у стабільні цифрові.

Гістерезис — властивість системи мати різні пороги спрацювання залежно від напрямку зміни сигналу (зростає чи спадає). Стан перемикається не в одній точці, а в двох різних.

KEY
Ключова ідея: Вихід не може «коливатись» навколо одного порогу, бо перехід вгору і перехід вниз відбуваються на різних напругах. Між ними — «мертва зона» нечутливості.
Компаратор (без гістерезису)
  • Один поріг: 2.0 В
  • Vin > 2.0В → 1
  • Vin < 2.0В → 0
  • Шум біля порогу → хибні фронти
Schmitt Trigger (з гістерезисом)
  • VTH+ = 2.0 В (перехід 0 → 1)
  • VTH− = 1.2 В (перехід 1 → 0)
  • Між 1.2В і 2.0В → стан зберігається
  • Шум в мертвій зоні → ігнорується
INF
Гістерезис = 1.2В–2.0В. Ширина мертвої зони визначається різницею порогів: ΔV = VTH+ − VTH− = 0.8В. Чим ширша зона, тим стабільніша робота при сильному шумі.
02

Проблема без Schmitt Trigger

Якщо сигнал повільно зростає або містить шум поблизу порогу, звичайний компаратор з одним порогом (2.0В) реагує на кожне коливання:

Signal · near threshold
// Шумний сигнал біля 2.0В
1.98В → 2.01В → 1.99В → 2.02В → 1.97В

// Компаратор видає:
   0  →    1  →    0  →    1  →    0    ← хибні фронти!
WRN
Мікроконтролер може пропустити переривання або відрахувати зайві імпульси, якщо GPIO входи не мають гістерезису. На практиці кожна хибна зміна стану GPIO — потенційна помилка в логіці програми.
Порівняння відгуку на шумний сигнал LIVE
Компаратор (VTH = 2.0В)
Schmitt Trigger (VTH+ = 2.0В, VTH− = 1.2В)
03

Принцип роботи

Schmitt Trigger має два порогових рівні. Вихід залежить від напрямку зміни вхідної напруги:

Thresholds
VTH+ = 2.0 В   // перехід 0 → 1 (напруга зростає)
VTH− = 1.2 В   // перехід 1 → 0 (напруга падає)

Між 1.2В і 2.0В вихід зберігає попередній стан — це і є гістерезис. Пересунь повзунок нижче і спостерігай за петлею гістерезису.

04

Використання

Застосовується скрізь, де потрібно уникнути хибних перемикань при повільних або шумних змінах сигналу.

Використання 01
GPIO входи мікроконтролерів

Вбудований Schmitt Trigger на GPIO входах STM32 та ESP32 дозволяє надійно розрізняти логічні 0 та 1 навіть при шумі на лінії. Це стандарт для всіх сучасних MCU.

C · STM32 HAL · GPIO Input
/* GPIO у STM32 має вбудований Schmitt Trigger за замовчуванням */
GPIO_InitTypeDef cfg = {0};
cfg.Pin  = GPIO_PIN_0;
cfg.Mode = GPIO_MODE_INPUT;   // Schmitt trigger вже вбудований
cfg.Pull = GPIO_NOPULL;
HAL_GPIO_Init(GPIOA, &cfg);

// Стабільне читання незважаючи на шум
GPIO_PinState state = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0);
Використання 02
Кнопки — усунення брязкоту

Кнопка при натисканні механічно «відскакує» і створює серію імпульсів (bounce). Schmitt Trigger допомагає перетворити це на чистіший сигнал, особливо в поєднанні з RC-фільтром.

Signal · Button bounce
// Без Schmitt Trigger — сигнал при натисканні:
0 1 0 1 0 1 1 1   ← bounce (хибні переривання)

// З Schmitt Trigger + RC (10кОм + 100нФ):
0 0 0 0 0 0 1 1   ← один чистий перехід
Використання 03
Після RC-ланцюгів

RC-фільтр «заокруглює» фронти сигналу — замість різкого перепаду виходить повільний перехід. Без гістерезису такий повільний сигнал поблизу порогу викликає хибні спрацьовування.

Signal · RC filter output
// RC-фільтр: повільний фронт замість різкого
0В ──── 0.3В ── 0.8В ── 1.4В ── 2.0В ── 3.3В
         ↑ без гістерезису — хибні спрацювання тут

// Schmitt Trigger ігнорує зону 1.2В–2.0В
0 ──────────────────────────────── 1
                                    ↑ переключення лише тут (2.0В)
Q&A — Питання на співбесіді
Що таке гістерезис і навіщо він потрібен у цифровій схемотехніці?›
Гістерезис — це властивість системи мати різні пороги реакції залежно від попереднього стану або напрямку зміни вхідного сигналу. У цифровій схемотехніці він потрібен, щоб виключити «дрижання» виходу поблизу порогу перемикання. Без гістерезису сигнал з шумом ±50мВ навколо порогу 2.0В може викликати десятки переключень на мікросекунду. З гістерезисом перемикання відбувається лише один раз — і вихід зберігає стан, поки сигнал не вийде за межі мертвої зони.
Яка різниця між звичайним компаратором і Schmitt Trigger?›
Компаратор має один поріг: якщо Vin > Vref — вихід HIGH, якщо менше — LOW. Поблизу порогу будь-який шум викликає коливання виходу.

Schmitt Trigger має два пороги: VTH+ для переходу LOW→HIGH і VTH− для переходу HIGH→LOW. Між ними — мертва зона, де вихід не змінюється незалежно від шуму. Чим ширша зона (більше VTH+ − VTH−), тим стабільніша робота.
Що станеться якщо сигнал «завис» між VTH− і VTH+?›
Нічого не станеться — і це саме бажана поведінка. Вихід Schmitt Trigger у мертвій зоні (1.2В – 2.0В) зберігає попередній стан. Якщо перед входом у зону вихід був HIGH — він залишиться HIGH. Якщо LOW — залишиться LOW. Це і є гістерезис: вихід «пам'ятає» звідки прийшов сигнал.
Чи є Schmitt Trigger вже вбудований в GPIO мікроконтролерів?›
Так, у більшості сучасних MCU — так. STM32: всі GPIO входи мають вбудований Schmitt Trigger, він активний автоматично в режимі Input. ESP32: аналогічно, цифрові входи GPIO мають вбудований гістерезис. Це означає, що базовий захист від шуму ти отримуєш безкоштовно. Для екстремальних умов (дуже сильний шум, RC-фільтри) розглядають зовнішні мікросхеми типу 74HC14 (інвертор із Schmitt Trigger входом).
Як Schmitt Trigger вирішує проблему брязкоту кнопки (button bounce)?›
При натисканні механічна кнопка протягом 1–10 мс «відскакує», генеруючи серію коротких імпульсів. Якщо підключити кнопку через RC-фільтр (наприклад 10кОм + 100нФ), він «розмаже» фронт, перетворивши bounce на повільне зростання напруги. Сам по собі RC-фільтр дає повільний перехід через поріг — потенційно хибні спрацьовування. Schmitt Trigger після RC «відрізає» цю повільну зону і перетворює сигнал на чіткий цифровий перехід. Разом RC + Schmitt Trigger — класичне апаратне усунення брязкоту.
